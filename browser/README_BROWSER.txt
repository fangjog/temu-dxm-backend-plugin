Put portable Chrome here if you want a fully bundled browser.

Supported examples:
- browser/chrome/chrome.exe
- browser/GoogleChromePortable/App/Chrome-bin/chrome.exe

If no portable Chrome is present, plugin_main.py falls back to installed Google Chrome.
The automation profile is stored under:
browser/user_data/Profile 13

This package intentionally does not include any existing Chrome profile, cookies, login state,
bookmarks, cache, or user credentials.
